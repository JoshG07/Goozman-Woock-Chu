# Dashboard Changelog

### Peer Feedback and Responses
- Add more data/increase data analysis

We totally switched our dataset from iNaturalist observations to Calfora. This provided significantly more observations and led to more interesting data analysis.


- Statistics and regressions

Now that we added additional data, we conducted regressions and t-tests for a couple of analyses, namely comparing changes in species in unburned vs burned areas and in single burn vs repeated burn areas.


- Put filters with respective maps instead of to the side

We looked into doing this, and it just doesn't work as we'd like with the app.py user interface. Also, the filters affect multiple figures, so we don't want them to look like they are only associated with one.


- Clearer explanation of the year slider

The year slider is titled fire year, so it should not be confused with species observation year. The corresponding graph is titled "Invasive plant observations within one year of a prescribed fire," which indicates that the species observations should come from the fire year +/- one year.
